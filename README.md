# 문득문득

고등학생이 국어 「문장의 구조와 확장」 단원에서 문장을 직접 만들고, 확장하고, 비교하고, 수정하도록 돕는 학교 수업용 AI 글쓰기 도우미입니다.

## 기술 구성

- Next.js + TypeScript
- Vercel
- Supabase Auth + Postgres + RLS
- OpenAI Responses API
- GitHub Actions + 하네스 검증

## 화면 버전

- `mondeuk-v2` Git 태그: 일일 문법 로드맵까지 완성된 복구 지점
- ver.3: 첫 화면 전체를 큰 문법책으로 구성합니다. 스크롤할 때 종이 앞·뒷면과 중앙 책등의 그림자가 드러나는 책장 넘김으로 각 장의 왼쪽 삽화와 오른쪽 설명이 교체됩니다. 표지를 첫 학습 장면 바로 위에 배치하여 표지가 넘어가는 동안 빈 종이가 노출되지 않습니다. 마지막 장의 제목은 `오늘의 문법책에 내 문장을 남겨 보세요.`이며 학교 계정으로 바로 로그인할 수 있습니다. 로그인 뒤 `오늘의 챌린지 → 스스로 유형 학습 → 오답노트`도 이동 순서에 따라 책장을 앞뒤로 넘깁니다. 움직임 축소 설정에서는 전환 없이 같은 기능을 제공합니다.
- 한국어 편집 디자인: 명조 제목과 산세리프 본문, 한지색·먹색·소나무빛·인주색을 공통 디자인 언어로 사용합니다. 낙관형 로고와 절제된 문양을 첫 화면, 로그인, 학생 대시보드, 학습 화면에 일관되게 적용합니다.
- 편집형 정보 구조: 학생 홈은 하나의 큰 대표 활동과 두 개의 보조 활동으로 비대칭 배치하고, 학습 상단 메뉴는 번호·기능 설명이 있는 중앙 탭으로 재구성합니다. 수업 화면은 큰 주제 표지, 현재 차시 시각물, 텍스트형 차시 목차, 오늘의 흐름으로 나누며 청회색·자주색·모래색을 함께 사용합니다.
- 전 화면의 본문과 제목은 산세리프 글꼴로 통일합니다. 로그인 전 책의 2~5장은 청회색·자주색·연두회색·살구색으로 구분하고, 로그인 뒤 학습 탭은 책장 전환 없이 즉시 이동하며 훈민정음 자형을 분리한 저채도 배경을 사용합니다.
- 학생 홈의 장식 문자는 훈민정음 자형 배경으로 통일하고, 오늘의 챌린지 표지는 현재 차시를 `현재/전체`로 표시하며 차시별 대표어 `기본·연결·확장·표현·변형·활용`을 보여 줍니다.

## 로컬 실행

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

OpenAI와 Supabase 키가 없는 개발 환경에서는 `/learn`에서 규칙 기반 비계 엔진으로 UI 흐름을 확인할 수 있습니다. `APP_ENV=production`에서는 필수 키와 인증이 없으면 AI 요청을 거부합니다.

## 검증

```bash
pnpm verify
pnpm build
```

`pnpm verify`는 lint, 타입, 단위 테스트, P1~P6 추적, 비밀값·RLS·HTTP 보안 헤더 정적 검사, eval 명세 검사를 실행합니다. 실제 운영 전에는 별도 Supabase 테스트 프로젝트에서 `supabase/tests/rls.sql`도 실행해야 합니다.

## 매일 문법 루틴

`/learn/self-study`는 문학 작품·실생활 자료·문장 만들기·개념학습을 4일 묶음마다 한 번씩, 날짜 기반의 섞인 순서로 제공하는 7일 로드맵입니다. 새로고침해도 그날의 유형은 바뀌지 않습니다. 오늘 노드를 누르면 같은 브라우저 탭이 `/learn/self-study/today`의 독립 학습 화면으로 전환됩니다. 학생이 자기 답을 쓰고 첫 AI 질문·피드백까지 받거나, 개념학습에서 단서를 거쳐 정답을 찾으면 해당 날짜가 완료되며 기존 `learning_events`의 학생별 RLS 범위 안에 완료 날짜가 저장됩니다. 시 활동은 구절 선택만으로 완료되지 않고, 선택을 바탕으로 제시된 질문에 학생이 직접 답해야 완료됩니다.
