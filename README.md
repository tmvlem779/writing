# 문득문득

고등학생이 국어 「문장의 구조와 확장」 단원에서 문장을 직접 만들고, 확장하고, 비교하고, 수정하도록 돕는 학교 수업용 AI 글쓰기 도우미입니다.

## 기술 구성

- Next.js + TypeScript
- Vercel
- Supabase Auth + Postgres + RLS
- OpenAI Responses API
- GitHub Actions + 하네스 검증

## 화면 버전

- `mondeuk-v2` Git 태그: 일일 문법 로드맵까지 완성된 복구 지점
- 첫 화면은 별도 소개·책장 전환 없이 학교 계정 로그인 화면으로 바로 이동합니다. 로그인 화면은 브랜드와 계정 입력에만 집중하며, 밝은 하늘색·연보라·분홍색 색면을 사용합니다.
- 한국어 편집 디자인: 명조 제목과 산세리프 본문, 한지색·먹색·소나무빛·인주색을 공통 디자인 언어로 사용합니다. 낙관형 로고와 절제된 문양을 첫 화면, 로그인, 학생 대시보드, 학습 화면에 일관되게 적용합니다.
- 편집형 정보 구조: 학생 홈은 하나의 큰 대표 활동과 두 개의 보조 활동으로 비대칭 배치하고, 학습 상단 메뉴는 번호·기능 설명이 있는 중앙 탭으로 재구성합니다. 수업 화면은 큰 주제 표지, 현재 차시 시각물, 텍스트형 차시 목차, 오늘의 흐름으로 나누며 청회색·자주색·모래색을 함께 사용합니다.
- 전 화면의 본문과 제목은 산세리프 글꼴로 통일합니다. 로그인 전 책의 2~5장은 청회색·자주색·연두회색·살구색으로 구분하고, 로그인 뒤 학습 탭은 책장 전환 없이 즉시 이동하며 훈민정음 자형을 분리한 저채도 배경을 사용합니다.
- 학생 홈의 장식 문자는 훈민정음 자형 배경으로 통일하고, 오늘의 챌린지 표지는 현재 차시를 `현재/전체`로 표시합니다. 큰 표지 영역은 학습 내용이 빨리 보이도록 압축합니다.

## 로컬 실행

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

OpenAI와 Supabase 키가 없는 개발 환경에서는 `/learn`에서 규칙 기반 비계 엔진으로 UI 흐름을 확인할 수 있습니다. `APP_ENV=production`에서는 필수 키와 인증이 없으면 AI 요청을 거부합니다.

## 검증

```bash
pnpm verify
pnpm build
```

`pnpm verify`는 lint, 타입, 단위 테스트, P1~P6 추적, 비밀값·RLS·HTTP 보안 헤더 정적 검사, eval 명세 검사를 실행합니다. 실제 운영 전에는 별도 Supabase 테스트 프로젝트에서 `supabase/tests/rls.sql`도 실행해야 합니다.

## 매일 문법 루틴

`/learn/self-study`는 문학 작품·실생활 자료·문장 만들기·개념학습·틀린 문장 고치기를 5일 묶음마다 한 번씩, 날짜 기반의 섞인 순서로 제공하는 30일 로드맵입니다. 새로고침해도 그날의 유형은 바뀌지 않습니다. 지그재그 노드와 날짜별 안내는 어느 위치에서도 같은 간격을 유지합니다. 오늘과 지난 날짜의 노드를 누르면 같은 브라우저 탭이 `/learn/self-study/today`의 독립 학습 화면으로 전환되며, 지난 날짜 학습은 다시 풀 수 있지만 완료·연속 학습 기록에는 포함되지 않습니다. 학생이 자기 답을 쓰고 첫 AI 질문·피드백까지 받거나, 개념학습에서 단서를 거쳐 정답을 찾거나, 오류 문장에서 잘못된 부분을 표시하고 바른 문장과 이유를 설명하면 오늘 날짜가 완료되며 기존 `learning_events`의 학생별 RLS 범위 안에 완료 날짜가 저장됩니다. 시 활동은 구절 선택만으로 완료되지 않고, 선택을 바탕으로 제시된 질문에 학생이 직접 답해야 완료됩니다.

## 반응형 화면

모바일(`360~640px`)은 학습 탭을 손가락으로 넘길 수 있는 가로 목록과 한 줄 로드맵으로, 태블릿(`641~1024px`)은 두 열 대시보드와 넓은 지그재그 로드맵으로 별도 조판합니다. 교사 화면도 같은 구간에서 현황 카드와 계정 생성 폼의 열 수를 줄여 겹침을 방지합니다. 제목·질문·버튼을 포함한 한국어 문장은 모든 구간에서 `word-break: keep-all`을 기본으로 사용합니다. 모바일은 좁은 행폭에 맞춘 자연스러운 어절 흐름, 태블릿은 중간 행폭, PC(`1025px~`)는 제목의 균형 잡힌 줄과 본문의 긴 호흡을 각각 적용합니다.

## 교사 학생 계정 관리

`/teacher`는 이름·학생 아이디·초기 비밀번호로 계정을 만들고, 담당 학급별 학생 계정 목록을 이름, 아이디, 사용 상태, 등록일과 함께 표시합니다. 계정 생성 직후 목록을 다시 불러오며, 학생 탭에서 `오늘의 챌린지`, `스스로 유형학습`, `오답노트` 현황을 나누어 확인합니다. 화면은 15초마다 새 기록을 확인하고 반복 오답·독립 성공 비율·비계 수준을 근거로 학습 정체 지점을 진단합니다. 조회는 로그인한 교사의 활성 학급 멤버십과 기존 RLS 범위 안에서만 수행됩니다.
