# 위협 모델

| 위협 | 통제 |
| --- | --- |
| 다른 학생 데이터 조회 | RLS deny-by-default, 교차 사용자 음성 테스트 |
| 교사 권한 위조 | 서버에서 Auth 사용자와 membership 재검증 |
| API 키 유출 | 서버 전용 환경 변수, Git 비밀 검사 |
| 프롬프트 주입 | 시스템 규칙과 학생 입력 분리, 구조화 출력 |
| 부적절한 미성년자 콘텐츠 | 입력·출력 moderation, 차단·신고 경로 |
| 비용 고갈 | 학생별 일일 제한, 월 비용 상한, 짧은 출력 |
| 대필 남용 | 비계 상태 머신, 완성문 선제 제공 금지 eval |
