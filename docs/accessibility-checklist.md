# 접근성 점검표

- 모든 입력에 보이는 `label`이 있다.
- 키보드 포커스가 명확하고 주요 동작을 키보드로 실행할 수 있다.
- 오류·상태 메시지는 `role="alert"` 또는 `role="status"`로 전달한다.
- 색만으로 단계나 상태를 구분하지 않는다.
- 모바일에서 학습 활동 목록을 가로 스크롤로 사용할 수 있다.
- 제목 계층과 랜드마크(`header`, `nav`, `main`, `section`)가 일관된다.
- AI 응답은 `aria-live="polite"`로 알린다.
- 실제 배포 전 키보드 전용, 200% 확대, 화면 낭독기, 색 대비를 수동 점검한다.
