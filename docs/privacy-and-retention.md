# 개인정보 및 보관 정책 초안

- 서비스는 특정 학교 수업에서 승인된 교사와 학생만 사용한다.
- 공개 회원가입은 비활성화한다.
- 이름·학번·학교명은 학습 기능에 꼭 필요한 범위에서만 수집한다.
- 학생 글과 대화는 기본적으로 계속 보관한다.
- 학교 관리자는 학생 또는 학급 단위로 데이터를 내보내고 삭제할 수 있다.
- OpenAI 요청에는 내부 식별자를 해시한 `safety_identifier`만 포함한다.
- OpenAI 응답 저장은 `store: false`를 사용한다.
- 운영 로그에는 학생 원문을 복제하지 않는다.
- 실제 운영 전 학교의 개인정보 처리방침과 적용 법률 검토가 필요하다.
