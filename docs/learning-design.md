## 장 구성

- 모든 장 위에는 1~5차시 공통 선택기를 둔다. 학생이 차시를 바꾸면 1장 개념, 2장 쓰기·성찰, 3장 실생활 탐구가 모두 같은 핵심 질문과 개념 범위로 전환된다.
- 1장 `개념 학습`: 2022 개정 교육과정 「화법과 언어」 교과서의 ‘문장의 구조’ 개념 흐름을 참고해 문장·절, 이어진문장, 안은문장, 구조와 표현 효과를 관찰 → 개념 정리 → 확인 순으로 학습한다. 세부 출처와 재구성 기준은 [`curriculum-alignment.md`](./curriculum-alignment.md)에 기록한다.
- 2장 `쓰기와 성찰`: 기존의 시작 진단, 문장 만들기, 문장 확장, 구조 비교, 오류 탐구, 짧은 글쓰기, 성찰을 유지한다. AI는 이 장에서 질문 → 단서 → 대조 → 부분 구조 → 직접 설명 순으로 비계를 조절한다.
- 3장 `실생활 글 탐구`: 기사, 안내문, 대화, 발표, 인터뷰, 학습자 SNS 형식을 본뜬 수업용 자료에서 구조 찾기 → 표현 효과 설명 → 목적과 독자에 맞게 직접 고쳐 쓰기를 수행한다. 자료는 저작권·개인정보 노출을 피하도록 모두 새로 작성한다.

## 5차시 공통 구조

| 차시 | 핵심 내용 | 핵심 질문 | 1장 → 2장 → 3장 연결 |
| --- | --- | --- | --- |
| 1차시 | 문장의 짜임과 홑문장·겹문장 | 문장의 구조는 어떻게 파악할 수 있을까? | 절과 주술 관계 관찰 → 구조 진단·생성 → 기사·안내문의 홑문장/겹문장 분석 |
| 2차시 | 이어진문장 | 문장과 문장은 어떻게 연결되는가? | 대등·종속 연결 개념 → 연결·결합·비교 → 안내문·대화의 연결 관계 재구성 |
| 3차시 | 안은문장 ① | 하나의 문장이 어떻게 다른 문장의 성분이 되는가? | 명사절·관형절·부사절 → 역할 분석·변형 → 기사·발표의 안긴절 분석 |
| 4차시 | 안은문장 ②와 문장 구조·의미 | 복잡한 문장 구조는 의미와 어떤 관계가 있을까? | 서술절·인용절·중의성 → 의미 비교·고쳐쓰기 → 인터뷰·SNS의 인용과 꾸밈 관계 점검 |
| 5차시 | 문장 생성과 종합 활동 | 내가 의도한 의미를 문장 구조로 표현할 수 있을까? | 구조 선택 원리 → 생성·자기 설명·상호 피드백·종합 평가 → 여섯 실제 자료 형식으로 전이 |

### 3장 활동과 설계 원리

| 단계 | 학생 행동 | 설계 원리 |
| --- | --- | --- |
| 구조 찾기 | 절의 경계, 이어진 방식, 안긴절의 기능을 자료 안에서 찾고 근거를 말한다. | P3, P4 |
| 효과 설명 | 자료의 목적과 독자를 고려해 정보 관계, 강조, 말투의 효과를 설명한다. | P3, P4, P6 |
| 고쳐 쓰기 | 기사·안내·대화 등 각 형식의 목적에 맞게 문장을 직접 재구성하고 이유를 설명한다. | P2, P5, P6 |
