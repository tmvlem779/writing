# 학습 설계 추적표

| ID | 학습 동작 | 구현 위치 | 대표 평가 |
| --- | --- | --- | --- |

| P2 | 학생의 단계적 생성·확장 | `system-prompt.ts`, 학습 화면 | AI가 완성문을 선제 제공하지 않음 |

## 장 구성

- 학생 화면에는 `구조+문법 요소` 여섯 차시만 제공하며 별도 수업안 선택기는 두지 않는다.
- 모든 장 위에는 차시 선택기를 둔다. 전 차시에 1장 개념 학습과 2장 쓰기·성찰을 제공한다.
- 1장 `개념 학습`: 2022 개정 교육과정 「화법과 언어」 교과서의 ‘문장의 구조와 문법 요소’ 흐름을 참고해 관찰 → 소주제별 개념 정리 → 여러 문항의 확인·설명 순으로 학습한다. `스스로 확인하기`는 세 문항에 대한 학생의 첫 판단을 모두 받은 뒤 최초 정오답을 한 번에 보여 준다. 이후 오답만 다시 풀게 하며, 모든 문항을 해결해야 2장 탭과 이동 버튼이 열린다. 오답에서는 정답을 공개하지 않고 다시 관찰할 단서만 제공한다. 세부 출처와 재구성 기준은 [`curriculum-alignment.md`](./curriculum-alignment.md)에 기록한다.
- 2장 `쓰기와 성찰`: 기존의 시작 진단, 문장 만들기, 문장 확장, 구조 비교, 오류 탐구, 짧은 글쓰기, 성찰을 유지한다. `제출`과 `AI 힌트`를 별도 행동으로 제공하고 학습 기록에서도 도움 없이 제출한 성취와 힌트 사용 뒤의 성취를 구분한다. 답을 제출한 뒤에는 입력란을 비워 다음 질문에 이전 답이 남지 않게 한다. AI는 질문 → 단서 → 대조 → 부분 구조 → 직접 설명 순으로 비계를 조절한다.
- 6차시 1장에는 교과서 파일 25~26쪽(교과서 110~111쪽)의 정리표를 새 문장으로 재구성한 입력형 정리 노트를 둔다. 학생이 제출하기 전에는 힌트를 숨기며, 확인 시 답을 입력해 제출한 오답 칸에만 각각의 관찰 단서와 목표 답의 음절 수를 제공한다. 정리 노트 17칸을 모두 맞히고 `스스로 확인하기` 3문항도 모두 통과해야 2장을 연다.
- 실생활 탐구 자료는 추후 재설계를 위해 데이터에 보존하되 현재 학생 화면의 3장은 노출하지 않는다.

## 여섯 차시 구조

| 차시 | 핵심 내용 | 핵심 질문 | 장 구성 |
| --- | --- | --- | --- |
| 1차시 | 문장의 기본 구조와 문장 생성 | 문장 성분을 어떻게 조합해야 뜻이 분명한 홑문장이 될까? | 1장 성분 역할 → 2장 홑문장 생성·구조 설명 |
| 2차시 | 이어진문장과 의미 관계 | 두 홑문장을 어떤 관계로 연결하면 의도가 잘 드러날까? | 1장 연결 관계 → 2장 나열·대조·원인·조건 생성·비교 |
| 3차시 | 안은문장과 문장 확대 | 짧은 문장을 절로 바꾸어 다른 문장 속에 어떻게 넣을까? | 1장 명사절·관형절·부사절 → 2장 결합·변형·효과 설명 |
| 4차시 | 종결·높임·시간 표현 | 종결·높임·시간 표현은 상황과 의미를 어떻게 드러낼까? | 1장 종결 기능·높임 대상·시제와 상 → 2장 상황별 변형·효과 설명 |
| 5차시 | 피동·사동·부정·인용 표현 | 피동·사동·부정·인용 표현은 정보의 초점과 관점을 어떻게 바꿀까? | 1장 네 문법 요소의 형태·의미 → 2장 변형·적절성 평가 |
| 6차시 | 구조와 문법 요소의 종합적 활용 | 상황에 맞는 구조와 문법 요소로 의도한 의미를 표현할 수 있을까? | 1장 입력형 소단원 정리·맥락별 선택 → 2장 생성·변형·자기 설명 |

### 실생활 탐구 활동과 설계 원리

| 단계 | 학생 행동 | 설계 원리 |
| --- | --- | --- |
| 구조 찾기 | 절의 경계, 이어진 방식, 안긴절의 기능을 자료 안에서 찾고 근거를 말한다. | P3, P4 |
| 효과 설명 | 자료의 목적과 독자를 고려해 정보 관계, 강조, 말투의 효과를 설명한다. | P3, P4, P6 |
| 고쳐 쓰기 | 기사·안내·대화 등 각 형식의 목적에 맞게 문장을 직접 재구성하고 이유를 설명한다. | P2, P5, P6 |
