| --- | --- | --- | --- |

## 장 구성

- 학습 화면의 수업안 선택기에서 기존 `A안 · 문장 구조 중심`과 새 `B안 · 구조+문법 요소`를 전환한다. 두 수업안은 별도 데이터로 유지해 수업 후 비교할 수 있다.
- 모든 장 위에는 1~5차시 공통 선택기를 둔다. A안은 1~4차시에 1·2장, 5차시에 1·2·3장을 제공한다. B안은 1~5차시 모두 1·2장으로 구성하고, 실생활 전이는 차시 밖의 `날개` 탭에서 제공한다.
- 1장 `개념 학습`: 2022 개정 교육과정 「화법과 언어」 교과서의 ‘문장의 구조와 문법 요소’ 흐름을 참고해 관찰 → 소주제별 개념 정리 → 여러 문항의 확인·설명 순으로 학습한다. 세부 출처와 재구성 기준은 [`curriculum-alignment.md`](./curriculum-alignment.md)에 기록한다.
- 2장 `쓰기와 성찰`: 기존의 시작 진단, 문장 만들기, 문장 확장, 구조 비교, 오류 탐구, 짧은 글쓰기, 성찰을 유지한다. AI는 이 장에서 질문 → 단서 → 대조 → 부분 구조 → 직접 설명 순으로 비계를 조절한다.
- 실생활 탐구: A안에서는 5차시의 3장으로, B안에서는 별도 `날개 · 실생활 탐구`로 제공한다. 기사, 안내문, 대화, 발표, 인터뷰, 학습자 SNS 형식을 본뜬 수업용 자료에 앞서 배운 개념을 종합 적용하고 구조 찾기 → 표현 효과 설명 → 목적과 독자에 맞게 직접 고쳐 쓰기를 수행한다. 기본 자료는 저작권·개인정보 노출을 피하도록 모두 새로 작성한다.

## 5차시 공통 구조

### A안 · 문장 구조 중심

| 차시 | 핵심 내용 | 핵심 질문 | 장 구성 |
| --- | --- | --- | --- |
| 1차시 | 문장의 짜임과 홑문장·겹문장 | 문장의 구조는 어떻게 파악할 수 있을까? | 1장 절과 주술 관계 관찰 → 2장 구조 진단·생성 |
| 2차시 | 이어진문장 | 문장과 문장은 어떻게 연결되는가? | 1장 대등·종속 연결 개념 → 2장 연결·결합·비교 |
| 3차시 | 안은문장 ① | 하나의 문장이 어떻게 다른 문장의 성분이 되는가? | 1장 명사절·관형절·부사절 → 2장 역할 분석·변형 |
| 4차시 | 안은문장 ②와 문장 구조·의미 | 복잡한 문장 구조는 의미와 어떤 관계가 있을까? | 1장 서술절·인용절·중의성 → 2장 의미 비교·고쳐쓰기 |
| 5차시 | 문장 생성과 종합 활동 | 내가 의도한 의미를 문장 구조로 표현할 수 있을까? | 1장 구조 선택 → 2장 생성·설명·평가 → 3장 여섯 실제 자료에 1~4차시 개념 종합 적용 |

### B안 · 구조+문법 요소

| 차시 | 핵심 내용 | 핵심 질문 | 장 구성 |
| --- | --- | --- | --- |
| 1차시 | 문장의 기본 구조와 문장 생성 | 문장 성분을 어떻게 조합해야 뜻이 분명한 홑문장이 될까? | 1장 성분 역할 → 2장 홑문장 생성·구조 설명 |
| 2차시 | 이어진문장과 의미 관계 | 두 홑문장을 어떤 관계로 연결하면 의도가 잘 드러날까? | 1장 연결 관계 → 2장 나열·대조·원인·조건 생성·비교 |
| 3차시 | 안은문장과 문장 확대 | 짧은 문장을 절로 바꾸어 다른 문장 속에 어떻게 넣을까? | 1장 명사절·관형절·부사절 → 2장 결합·변형·효과 설명 |
| 4차시 | 문법 요소와 의미 변화 | 같은 기본 문장은 문법 요소에 따라 의미와 태도가 어떻게 달라질까? | 1장 시간·높임·피동/사동·부정 → 2장 변형·의미 비교 |
| 5차시 | 구조와 문법 요소의 종합적 활용 | 상황에 맞는 구조와 문법 요소로 의도한 의미를 표현할 수 있을까? | 1장 맥락별 선택 → 2장 생성·변형·자기 설명 |
| 날개 | 실생활 탐구 | 구조와 문법 요소를 실제 언어 자료에 어떻게 적용할까? | 여섯 실제 자료의 맥락 분석 → 구조·문법 요소 찾기 → 효과 평가 → 고쳐 쓰기 |

### 실생활 탐구 활동과 설계 원리

| 단계 | 학생 행동 | 설계 원리 |
| --- | --- | --- |
| 구조 찾기 | 절의 경계, 이어진 방식, 안긴절의 기능을 자료 안에서 찾고 근거를 말한다. | P3, P4 |
| 효과 설명 | 자료의 목적과 독자를 고려해 정보 관계, 강조, 말투의 효과를 설명한다. | P3, P4, P6 |
| 고쳐 쓰기 | 기사·안내·대화 등 각 형식의 목적에 맞게 문장을 직접 재구성하고 이유를 설명한다. | P2, P5, P6 |
