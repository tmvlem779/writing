# 학습 설계 추적표

| ID | 학습 동작 | 구현 위치 | 대표 평가 |
| --- | --- | --- | --- |
| P1 | 진단과 적응적 비계 | `state-machine.ts` | 실패 시 상승, 독립 성공 시 감소 |
| P2 | 학생의 단계적 생성·확장 | `system-prompt.ts`, 학습 화면 | AI가 완성문을 선제 제공하지 않음 |
| P3 | 관찰·분석·설명·생성·평가 질문 | `fallback.ts`, 프롬프트 | 답 뒤에 근거 질문 |
| P4 | 구조와 의미·초점 비교 | 활동 선택과 응답 mode | 둘 이상의 문장 비교 |
| P5 | 오류 탐구와 직접 수정 | `fallback.ts`, 프롬프트 | 오류를 먼저 찾게 함 |
| P6 | 새 상황 전이와 성찰 | 전이·성찰 활동, `history/page.tsx` | 전후 글과 도움 사용 성찰 |

모든 AI 변경은 관련 ID를 PR 설명과 eval 이름에 포함한다.
