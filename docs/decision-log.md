# 결정 기록

## ADR-001: 학교 초대형 이메일 인증

- 상태: 채택
- 결정: 교사가 학생 이메일을 초대하고 학생이 링크에서 비밀번호를 설정한다. 공개 회원가입은 제공하지 않는다.
- 이유: 특정 학교 수업 범위를 유지하고 계정 오남용을 줄인다.
- 추후: 학교가 Google Workspace SSO를 요구하면 별도 ADR로 변경한다.

## ADR-002: 서버 소유 AI 호출과 데이터 저장

- 상태: 채택
- 결정: OpenAI 호출, 안전 검사, 비용 검사, 학습 기록 저장은 Next.js 서버에서 수행한다.
- 이유: 비밀키를 보호하고 운영 우회를 막는다.

## ADR-003: 저비용 기본 모델

- 상태: 채택
- 결정: 기본 모델은 `gpt-5-nano`, 앱 내부 월 한도는 미화 6달러, 학생별 하루 40턴·세션별 30턴이다.
- 이유: 월 10,000원 목표에 환율 변동과 운영 여유를 두면서 Responses API 구조화 출력과 짧은 단계적 피드백을 지원한다.

## ADR-004: Instagram 실제 자료 연동 경계

- 상태: 제안 — 학교 개인정보·미성년자 보호 검토와 계정 선택 전에는 구현하지 않음
- 제안: 학생 개인 계정을 각각 연결하지 않는다. 교사가 관리하고 게시물 사용을 승인한 학급용 Instagram 프로페셔널 계정 하나를 공식 Instagram API로 읽는 방식을 우선한다.
- 최소 수집: 수업에 선택된 게시물의 본문과 게시물 식별자만 서버에서 가져오며, 학생 사용자명·프로필 사진·댓글·좋아요·위치·팔로워 정보는 저장하거나 학생 화면에 노출하지 않는다.
- 보안: OAuth 토큰은 서버에서 암호화해 보관하고 브라우저·로그·Git에 넣지 않는다. 연결 해제와 토큰 삭제 절차를 제공한다.
- 이유: 공식 API는 프로페셔널 계정을 중심으로 제공되며, 학생 개인 SNS의 연결은 수업 목적에 비해 개인정보와 동의 부담이 크다.

# 2026-10-01 · 저비용 모델과 응답 대기 피드백

- 문득문득의 짧은 구조화 질문 생성에는 비용 민감·대량 처리용 `gpt-5.6-luna`를 기본으로 사용한다.
- 지연 중 중복 제출을 막는 것에 더해, 버튼 안과 작업 영역에 `문·득·문·득` 로딩 표시를 함께 제공한다.
- 애니메이션은 `prefers-reduced-motion` 환경에서 정지하며 텍스트 상태 안내를 유지한다.
- 월 $6 제한은 실제 호출 모델별 입력·출력 단가로 계산하고, 등록되지 않은 모델은 비용을 과소 계산하지 않도록 보수적인 상한 단가를 적용한다.
