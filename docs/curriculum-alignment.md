# 2022 개정 교육과정 교과서 정합성 기록

## 적용 범위

- 참고 자료: 비상교육 고등학교 「화법과 언어」 교사용 교과서
- 확인 단원: 2. 언어의 탐구와 실제 → (3) 문장 → 탐구 1 「문장의 구조」
- 확인 쪽: 88~95쪽
- 사용 원칙: 교과서의 개념 배열과 범주만 참고하고, 서비스의 설명·예문·확인 문항은 새로 작성한다. 원본 PDF는 `references/textbook/`에만 두고 Git에서 제외한다.

## 1장 개념 학습 매핑

| 서비스 단계 | 교과서 개념 | 학생 활동 | 설계 원리 |
| --- | --- | --- | --- |
| 1. 문장은 어떻게 커질까? | 문장, 절, 홑문장과 겹문장 | 주어·서술어 관계의 횟수를 관찰하고 두 문장 유형을 구분 | P3 관찰·분석 |
| 2. 절과 절은 어떻게 이어질까? | 대등하게/종속적으로 연결된 이어진문장 | 연결 어미와 절 사이 의미 관계를 함께 설명 | P3 근거 설명, P4 구조·의미 연계 |
| 3. 한 절이 다른 절 안에 들어가면? | 명사절·관형절·부사절·서술절·인용절을 가진 안은문장 | 안긴절의 경계와 문장 안 기능을 확인 | P3 분석·설명 |
| 4. 왜 구조를 바꾸어 쓸까? | 홑문장·겹문장의 표현 효과 | 같은 사건을 분리하거나 연결하며 관계·강조·배경화 차이를 판단 | P4 구조·표현 효과 |

## 2장과의 연결

1장의 개념 확인 뒤 2장에서 기존의 시작 진단 → 문장 만들기 → 문장 확장 → 구조 비교 → 오류 탐구 → 짧은 글쓰기 → 성찰 활동을 수행한다. 1장은 개념을 관찰하고 분류하는 준비 단계이며, 2장은 학생이 직접 생성·수정·설명하고 AI의 단계적 비계를 받는 적용 단계다.

## 교육학 검토

- 오답을 고르자마자 정답을 노출하지 않고 관찰 질문으로 되돌린다.
- 정답 확인 뒤에도 판단 근거와 구조 변화의 효과를 설명하게 한다.
- 예문은 학교생활에 가까운 새 문장으로 구성하고 교과서 활동 문장을 복제하지 않는다.
- 개념 학습을 건너뛰어야 하는 수업 상황을 고려해 2장 이동을 강제로 잠그지 않는다.
