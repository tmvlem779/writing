# 2022 개정 교육과정 교과서 정합성 기록

## 적용 범위

- 참고 자료: 비상교육 고등학교 「화법과 언어」 교사용 교과서
- 확인 단원: 2. 언어의 탐구와 실제 → (3) 문장 → 탐구 1 「문장의 구조」, 탐구 2 「문법 요소」
- 확인 쪽: 86~111쪽
- 사용 원칙: 교과서의 개념 배열과 범주만 참고하고, 서비스의 설명·예문·확인 문항은 새로 작성한다. 원본 PDF는 `references/textbook/`에만 두고 Git에서 제외한다.

## 2장과의 연결

각 차시의 1장 개념 확인 뒤 2장에서 해당 차시의 분석·생성·비교·수정·성찰 과제를 수행한다. 1장은 개념을 관찰하고 분류하는 준비 단계이며, 2장은 학생이 직접 생성·수정·설명하고 AI의 단계적 비계를 받는 적용 단계다.

현재 학생 화면은 모든 차시에 1장과 2장만 제공한다. 기존 실생활 탐구 자료는 추후 재설계를 위해 코드에 보존하지만 3장으로 노출하지 않는다.

## 교육학 검토

- 오답을 고르자마자 정답을 노출하지 않고 관찰 질문으로 되돌린다.
- 정답 확인 뒤에도 판단 근거와 구조 변화의 효과를 설명하게 한다.
- 예문은 학교생활에 가까운 새 문장으로 구성하고 교과서 활동 문장을 복제하지 않는다.
- 개념의 독립 확인을 보장하기 위해 현재 차시의 확인 문항을 모두 통과하기 전에는 2장 탭과 이동 버튼을 잠근다.

## 구조+문법 요소 여섯 차시 매핑

교과서 86~111쪽의 문장 성분 복습, 문장의 구조, 문법 요소, 담화 맥락에 따른 선택 흐름을 6차시로 재구성한다.

| 차시 | 교과서 개념 | 학생 활동 | 표현 효과 초점 |
| --- | --- | --- | --- |
| 1. 문장의 기본 구조와 문장 생성 | 문장 성분, 홑문장 | 성분을 조합해 홑문장을 만들고 각 성분과 주술 관계를 설명 | 정보의 구체성 |
| 2. 이어진문장과 의미 관계 | 대등·종속 연결, 연결 어미 | 두 홑문장을 나열·대조·원인·조건 관계로 결합 | 사건 사이 관계 |
| 3. 안은문장과 문장 확대 | 명사절·관형절·부사절, 전성 어미 | 짧은 문장을 세 종류의 안긴절로 바꾸어 확대 | 정보의 포함과 꾸밈 |
| 4. 종결·높임·시간 표현 | 문장 종결법, 상대·주체·객체 높임, 시제와 상 | 화자·청자·상황과 사건의 시간을 바꾸어 문장을 변형하고 효과 설명 | 문장 기능, 참여자 관계, 시간과 진행 모습 |
| 5. 피동·사동·부정·인용 표현 | 피동법·사동법, 안/못 부정, 직접·간접 인용 | 행위 주체와 초점, 부정 의미·범위, 인용 관점을 비교하고 변형 | 행위 초점, 의지·능력, 전달 관점 |
| 6. 구조와 문법 요소의 종합적 활용 | 소단원 정리, 담화 맥락에 적절한 구조와 문법 요소 선택 | 정리표 빈칸을 직접 채우고 화자·청자·목적에 맞춰 문장을 생성·변형 | 개념 연결, 맥락 적절성과 화자 태도 |

### 재구성 원칙

- 교과서의 정의·범주·학습 순서를 정합성 기준으로 삼되 예문과 확인 문항은 학교생활 맥락으로 새로 작성한다.
- 4차시와 5차시의 문법 요소를 단순 암기 목록으로 제시하지 않고, 하나의 기본 문장이 어떻게 달라지는지 비교한다.
- 6차시 1장의 정리 노트는 PDF 파일 25~26쪽(교과서 110~111쪽)의 범주와 배열을 참고하되 문장과 힌트를 새로 작성한다.
- 6차시 정리 노트는 학생이 입력한 칸만 독립적으로 채점한다. 제출 전에는 힌트를 숨기고, 제출한 오답 칸에만 완성 답 대신 관련 개념을 다시 보는 개별 단서와 목표 답의 음절 수를 제공한다.
- 6차시는 정리 노트 17칸 전체 정답과 `스스로 확인하기` 3문항 전체 통과를 모두 충족해야 2장으로 이동할 수 있다.
- 종결·높임·시간 표현은 4차시, 피동·사동·부정·직접·간접 인용은 5차시에서 상세히 익힌 뒤 6차시 자료의 맥락 분석 요소로 연계한다.
- 각 개념 차시는 교과서의 하위 범주를 최소 3개 소주제로 나누고, 서로 다른 판단을 요구하는 자기 확인 문항을 3개 이상 제공한다.
