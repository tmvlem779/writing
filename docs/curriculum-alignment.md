- 참고 자료: 비상교육 고등학교 「화법과 언어」 교사용 교과서
- 확인 단원: 2. 언어의 탐구와 실제 → (3) 문장 → 탐구 1 「문장의 구조」, 탐구 2 「문법 요소」
- 확인 쪽: 86~111쪽
- 사용 원칙: 교과서의 개념 배열과 범주만 참고하고, 서비스의 설명·예문·확인 문항은 새로 작성한다. 원본 PDF는 `references/textbook/`에만 두고 Git에서 제외한다.

## 2장과의 연결

각 차시의 1장 개념 확인 뒤 2장에서 해당 차시의 분석·생성·비교·수정·성찰 과제를 수행한다. 1장은 개념을 관찰하고 분류하는 준비 단계이며, 2장은 학생이 직접 생성·수정·설명하고 AI의 단계적 비계를 받는 적용 단계다.

3장은 5차시에만 제공한다. 1~4차시에서 익힌 개념과 전략을 기사, 안내문, 대화, 발표, 인터뷰, 학습자 SNS 형식의 수업용 자료에 종합 전이한다. 각 자료에서 홑문장·겹문장, 이어진문장, 다섯 안긴절, 구조와 의미를 차례로 되짚고 구조 찾기 → 표현 효과 설명 → 고쳐 쓰기 순으로 탐구한다.

## 교육학 검토

- 오답을 고르자마자 정답을 노출하지 않고 관찰 질문으로 되돌린다.
- 정답 확인 뒤에도 판단 근거와 구조 변화의 효과를 설명하게 한다.
- 예문은 학교생활에 가까운 새 문장으로 구성하고 교과서 활동 문장을 복제하지 않는다.
- 개념 학습을 건너뛰어야 하는 수업 상황을 고려해 2장 이동을 강제로 잠그지 않는다.

## B안 · 구조+문법 요소 매핑

기존 A안은 위 매핑 그대로 보존한다. B안은 교과서 86~111쪽의 문장 성분 복습, 문장의 구조, 문법 요소, 담화 맥락에 따른 선택 흐름을 5차시로 재구성한다.

| 차시 | 교과서 개념 | 학생 활동 | 표현 효과 초점 |
| --- | --- | --- | --- |
| 1. 문장의 기본 구조와 문장 생성 | 문장 성분, 홑문장 | 성분을 조합해 홑문장을 만들고 각 성분과 주술 관계를 설명 | 정보의 구체성 |
| 2. 이어진문장과 의미 관계 | 대등·종속 연결, 연결 어미 | 두 홑문장을 나열·대조·원인·조건 관계로 결합 | 사건 사이 관계 |
| 3. 안은문장과 문장 확대 | 명사절·관형절·부사절, 전성 어미 | 짧은 문장을 세 종류의 안긴절로 바꾸어 확대 | 정보의 포함과 꾸밈 |
| 4. 문법 요소와 의미 변화 | 시간 표현의 시제·상, 상대·주체·객체 높임, 피동·사동, 안/못 부정 | 같은 기본 문장을 문법 요소별로 변형하고 의미·초점·태도 비교 | 시간, 참여자 관계, 행위 초점, 의지·능력 |
| 5. 구조와 문법 요소의 종합적 활용 | 담화 맥락에 적절한 문법 요소 선택, 종결·인용 표현과의 연계 | 화자·청자·목적에 맞춰 문장을 생성·변형하고 선택 이유 설명 | 맥락 적절성과 화자 태도 |

### 재구성 원칙

- 교과서의 정의·범주·학습 순서를 정합성 기준으로 삼되 예문과 확인 문항은 학교생활 맥락으로 새로 작성한다.
- 4차시에서 많은 문법 요소를 단순 암기 목록으로 제시하지 않고, 하나의 기본 문장이 어떻게 달라지는지 비교한다.
- B안 5차시는 생성·변형·자기 설명으로 마무리하고, 기사·안내문·대화·발표·인터뷰·학습자 SNS의 전이 활동은 별도 `날개` 탭에서 제공한다.
- 직접·간접 인용과 종결 표현은 교과서 범위에 포함되므로 4·5차시의 상세 개념과 날개 자료의 맥락 분석 요소로 연계한다.
- B안의 각 개념 차시는 교과서의 하위 범주를 최소 3개 소주제로 나누고, 서로 다른 판단을 요구하는 자기 확인 문항을 3개 이상 제공한다.
