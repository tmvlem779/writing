# 제품 요구사항

## 사용자

- 특정 학교 수업의 고등학생
- 해당 학생을 지도하는 교사

## 핵심 흐름

학생은 교사 초대 이메일로 계정을 시작하고 로그인한다. 1장에서 문장 구조 개념을 학습하고, 2장에서 시작 진단·문장 만들기·문장 확장·구조 비교·오류 탐구·짧은 글쓰기·성찰을 진행한다. 3장에서는 기사·안내문·대화·발표·인터뷰·학습자 SNS 형식의 수업용 자료를 분석하고 목적에 맞게 고쳐 쓴다. AI는 질문부터 시작해 필요한 만큼만 도움을 높인다. 학생은 자신의 최근 학습과 독립 성공 기록을 확인한다.

교사는 학급에 학생을 초대하고, 학생별 세션 수·독립 성공·사용한 최대 비계 수준을 확인한다. 다른 학급이나 무관한 학생의 데이터는 볼 수 없다.

## 운영 제약

- 한국어 전용
- 학생 로그인 필수, 공개 회원가입 없음
- 학생 글과 학습 대화는 Supabase에 계속 보관
- 월 OpenAI 비용 10,000원 이내
- OpenAI와 Supabase 관리자 키는 서버에서만 사용
- 운영 환경에서 인증·안전·예산·저장 실패를 우회하지 않음
