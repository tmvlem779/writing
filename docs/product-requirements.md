# 제품 요구사항

## 사용자

- 특정 학교 수업의 고등학생
- 해당 학생을 지도하는 교사

## 핵심 흐름

학생은 교사 초대 이메일로 계정을 시작하고 로그인한 뒤 구조와 문법 요소를 함께 다루는 여섯 차시 중 오늘 수업을 선택한다. 1~5차시에서 문장의 기본 구조, 이어진문장, 안은문장과 문법 요소를 학습하고, 6차시에서 핵심 개념을 직접 빈칸에 정리한 뒤 상황에 맞는 문장을 생성·변형·설명한다. 6차시의 실생활 자료 챕터는 추후 수업 재설계를 위해 현재 학생 화면에서는 제공하지 않는다. AI는 현재 차시의 핵심 질문과 과제 범위 안에서 질문부터 시작해 필요한 만큼만 도움을 높인다. 학생은 자신의 최근 학습과 독립 성공 기록을 확인한다.

교사는 학급에 학생을 초대하고, 학생별 세션 수·독립 성공·사용한 최대 비계 수준을 확인한다. 다른 학급이나 무관한 학생의 데이터는 볼 수 없다.

## 운영 제약

- 한국어 전용
- 학생 로그인 필수, 공개 회원가입 없음
- 학생 글과 학습 대화는 Supabase에 계속 보관
- 월 OpenAI 비용 10,000원 이내
- OpenAI와 Supabase 관리자 키는 서버에서만 사용
- 운영 환경에서 인증·안전·예산·저장 실패를 우회하지 않음
