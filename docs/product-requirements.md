# 제품 요구사항

## 사용자

- 특정 학교 수업의 고등학생
- 해당 학생을 지도하는 교사

## 핵심 흐름

학생은 교사 초대 이메일로 계정을 시작하고 로그인한다. 먼저 기존 A안(문장 구조 중심)과 새 B안(구조+문법 요소) 가운데 비교할 수업안을 고른 뒤 1~5차시에서 오늘 수업을 선택한다. 1~4차시에서는 1장의 개념과 2장의 분석·생성·수정·성찰을 수행한다. 5차시에서는 여기에 3장의 기사·안내문·대화·발표·인터뷰·학습자 SNS 종합 분석과 재구성을 더한다. AI는 현재 수업안·차시의 핵심 질문과 과제 범위 안에서 질문부터 시작해 필요한 만큼만 도움을 높인다. 학생은 자신의 최근 학습과 독립 성공 기록을 확인한다.

교사는 학급에 학생을 초대하고, 학생별 세션 수·독립 성공·사용한 최대 비계 수준을 확인한다. 다른 학급이나 무관한 학생의 데이터는 볼 수 없다.

## 운영 제약

- 한국어 전용
- 학생 로그인 필수, 공개 회원가입 없음
- 학생 글과 학습 대화는 Supabase에 계속 보관
- 월 OpenAI 비용 10,000원 이내
- OpenAI와 Supabase 관리자 키는 서버에서만 사용
- 운영 환경에서 인증·안전·예산·저장 실패를 우회하지 않음
