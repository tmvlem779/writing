# 제품 요구사항

## 사용자

- 특정 학교 수업의 고등학생
- 해당 학생을 지도하는 교사

## 핵심 흐름

학생은 교사가 만든 학교 아이디로 로그인한 뒤 `오늘의 챌린지`, `스스로 유형 학습`, `오답노트`를 선택한다. 오늘의 챌린지에서는 구조와 문법 요소를 함께 다루는 여섯 차시 중 오늘 수업을 학습한다. 스스로 유형 학습에서는 문학 작품과 실생활 자료를 탐구하고, 그림 속 학교생활 상황을 관찰해 자신의 첫 문장을 만든 뒤 AI 질문에 따라 확장·수정·설명한다. AI는 학생의 문장을 대신 완성하지 않고 질문부터 시작해 필요한 만큼만 도움을 높인다. 학생은 자신의 최근 학습과 독립 성공 기록을 확인한다.

ver.2에서는 별도 `AI 진단평가` 진입 탭을 노출하지 않는다. 기존 진단 코드와 기록은 ver.1 복구 및 과거 오답 조회를 위해 삭제하지 않는다.

교사는 학급에 학생을 초대하고, 학생별 세션 수·독립 성공·사용한 최대 비계 수준을 확인한다. 다른 학급이나 무관한 학생의 데이터는 볼 수 없다.

## 운영 제약

- 한국어 전용
- 학생 로그인 필수, 공개 회원가입 없음
- 학생 글과 학습 대화는 Supabase에 계속 보관
- 월 OpenAI 비용 10,000원 이내
- OpenAI와 Supabase 관리자 키는 서버에서만 사용
- 운영 환경에서 인증·안전·예산·저장 실패를 우회하지 않음
